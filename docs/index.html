Train a Neural Network in CUDA from Scratch

How it was built

Part 1: Plumbing and Data

Error checking, device buffers, and a deterministic spiral dataset that a straight line cannot separate.

Part 2: The Forward Pass

Matrix multiply, bias, ReLU, softmax and cross-entropy as one-thread-per-output kernels, then the model's parameters, its buffers and the full forward pass.

Part 3: The Backward Pass

Derive the gradients with the chain rule, write each as a kernel, and check them against a CPU reference and finite differences.

Part 4: Training

Gradient descent as a kernel, one training step that chains everything, and the loop that trains the network.

Part 5: Evaluation and Timing

Count correct predictions with an atomic counter, check the trained network on held-out points, and measure what a training step costs.
